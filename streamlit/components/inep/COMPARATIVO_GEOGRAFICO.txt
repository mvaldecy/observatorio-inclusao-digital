   🏛️ Piauí (estadual)

2. SUPORTA:
   ✓ Indicadores únicos
   ✓ Indicadores múltiplos (comparativos)
   ✓ Filtros adicionais (dependência, localização, etc)
   ✓ Análise automática por região

3. VISUALIZAÇÕES:
   ✓ Cards individuais por região com KPIs
   ✓ Gráficos de barras por região
   ✓ Tabela comparativa consolidada
   ✓ Gráfico comparativo entre regiões
   ✓ Download em CSV

================================================================================
ESTRUTURA DO COMPONENTE
================================================================================

Classe: ComparativoGeograficoINEP

Métodos principais:
  • renderizar()              - Método principal público
  • _analisar_regioes()       - Analisa dados por região
  • _renderizar_cards()       - Renderiza cards individuais
  • _renderizar_card_regiao() - Renderiza card de uma região
  • _renderizar_consolidado() - Renderiza comparativo geral

================================================================================
COMO USAR
================================================================================

Na página Streamlit:

```python
from components.inep import ComparativoGeograficoINEP

# Criar instância
comparativo = ComparativoGeograficoINEP(analisador)

# Renderizar comparativo
comparativo.renderizar(
    indicador='IN_INTERNET',           # ou lista para comparativo
    filtros_extras={'TP_DEPENDENCIA': 3},  # opcional
    is_multiple=False                   # True para comparativos
)
```

================================================================================
INTEGRAÇÃO NA PÁGINA INEP
================================================================================

Localização: Após "Análise por Agregador" e antes de "Resumo Estatístico"

Ativação: Checkbox "Comparar Brasil / Nordeste / Piauí"

Quando ativado:
  1. Cria instância do ComparativoGeograficoINEP
  2. Pega filtros aplicados (exceto geográficos)
  3. Renderiza comparativo completo

================================================================================
LÓGICA DE FILTRAGEM
================================================================================

BRASIL:
  - Todos os dados (sem filtro geográfico)
  - Aplica filtros extras (dependência, localização, etc)

NORDESTE:
  - Filtra: CO_REGIAO == 2
  - Aplica filtros extras

PIAUÍ:
  - Filtra: CO_UF == 22
  - Aplica filtros extras

NOTA: Filtros geográficos do sidebar são IGNORADOS no comparativo
      para garantir a comparação entre as 3 regiões

================================================================================
CASOS DE USO
================================================================================

1. COMPARAR ACESSO À INTERNET:
   Indicador: IN_INTERNET
   Resultado: % de escolas com internet em cada região

2. COMPARAR INFRAESTRUTURA:
   Indicador: [IN_INTERNET, IN_BANDA_LARGA, IN_LABORATORIO_INFORMATICA]
   Resultado: Múltiplos indicadores comparados

3. COMPARAR ESCOLAS RURAIS:
   Indicador: IN_INTERNET
   Filtros: TP_LOCALIZACAO=2
   Resultado: Internet em escolas rurais por região

4. COMPARAR ESCOLAS MUNICIPAIS:
   Indicador: Qualquer
   Filtros: TP_DEPENDENCIA=3
   Resultado: Comparação apenas de escolas municipais
