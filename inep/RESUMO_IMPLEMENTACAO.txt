📖 COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BÁSICO:
```python
from streamlit.utils.data_loader import get_analisador_inep
from inep import get_label, formatar_valor

# Criar analisador
analisador = get_analisador_inep(ano=2024)

# Filtrar escolas municipais rurais do Piauí
analisador.filtrar_dados(CO_UF=22, TP_DEPENDENCIA=3, TP_LOCALIZACAO=2)

# Analisar acesso à internet
resultado = analisador.analisar_indicador('IN_INTERNET')
print(resultado)
```

AGREGADORES:
```python
# Comparar dependências administrativas
resultado = analisador.analisar_por_agregador(
    indicador=['IN_INTERNET', 'IN_BANDA_LARGA'],
    campo_agregador='TP_DEPENDENCIA'
)
```

MÚLTIPLOS INDICADORES:
```python
resultado = analisador.analisar_indicador([
    'IN_INTERNET',
    'IN_LABORATORIO_INFORMATICA',
    'IN_BANDA_LARGA',
    'IN_INTERNET_ALUNOS'
])
```

RESUMOS ESPECIALIZADOS:
```python
# Resumo de infraestrutura tecnológica
resumo = analisador.resumo_infraestrutura(CO_UF=22)

# Análise rápida de internet
resultado = analisador.analisar_acesso_internet(
    CO_UF=22,
    TP_LOCALIZACAO=2
)
```

INTERNET E TECNOLOGIA:
  • IN_INTERNET                  - Acesso à internet
  • IN_BANDA_LARGA              - Banda larga
  • IN_LABORATORIO_INFORMATICA  - Laboratório de informática
  • IN_INTERNET_ALUNOS          - Internet para alunos
  • IN_INTERNET_APRENDIZAGEM    - Internet para ensino
  • QT_DESKTOP_ALUNO            - Computadores para alunos
  • QT_COMP_PORTATIL_ALUNO      - Notebooks para alunos
  • QT_TABLET_ALUNO             - Tablets para alunos

LOCALIZAÇÃO:
  • CO_REGIAO       - Região (1-5)
  • CO_UF           - UF (22=Piauí)
  • CO_MUNICIPIO    - Município
  • TP_LOCALIZACAO  - Urbana(1) / Rural(2)

CARACTERIZAÇÃO:
  • TP_DEPENDENCIA             - Federal(1) / Estadual(2) / Municipal(3) / Privada(4)
  • TP_SITUACAO_FUNCIONAMENTO  - Situação da escola

QUANTITATIVOS:
  • QT_MAT_BAS   - Total de matrículas
  • QT_MAT_FUND  - Ensino fundamental
  • QT_MAT_MED   - Ensino médio
  • QT_DOC_BAS   - Total de docentes
